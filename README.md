# Fullscreen Timer Minimal

A lightweight, distraction-free fullscreen stopwatch and countdown timer. The dashboard intentionally displays **only the time**.

## Run

Open `index.html` in a modern browser, or serve this directory with any static web server.

## Keyboard controls

| Key | Action |
| --- | --- |
| `Space` | Start / pause |
| `R` | Reset |
| `S` | Switch stopwatch / countdown |
| `F` | Toggle fullscreen |
| `↑` / `↓` | Add / subtract one minute (countdown) |
| `→` / `←` | Add / subtract ten seconds (countdown) |

The countdown starts at five minutes. Time adjustment is available in countdown mode. No visible controls or instructional text are rendered in the timer dashboard.

## Deployment

This is a static site. It can be hosted on GitHub Pages, Cloudflare Pages, Netlify, or any static web host. For GitHub Pages, publish the repository root.

## Inspiration

A clean-room implementation inspired by the idea of the [Fullscreen Timer by alphakevin](https://github.com/alphakevin/fullscreen-timer). This project does not include the original project's source files or assets.
